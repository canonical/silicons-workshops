# sdk/snap/snapcraft/

This directory contains the workshop-owned snapcraft.yaml used by the Snap
Packaging SDK to build the Ubuntu Core kernel snap.

The snap is built using the Snapcraft Kernel plugin with:
  plugin: kernel
  kernel-ubuntu-debian-package: true

This means Snapcraft handles both the kernel .deb build (via debian/rules) and
the final snap assembly in a single run. The kernel source tree does NOT need to
ship its own snapcraft.yaml.

The snapcraft.yaml in this directory is generated by the create-workshop skill
from config/workshop.yaml values:
  ubuntu.core_base       -> build-base:   (a kernel snap has no `base:`)
  toolchain.arch         -> architectures: (core20/core22) or platforms: (core24+)
  kernel.config.value    -> kernel-ubuntu-kconfigflavour:
  kernel flavour         -> name: linux-<flavour> (e.g. linux-mtk)
  kernel-src/            -> parts.kernel.source: ../../../kernel-src

Only the core22 form has been exercised end to end. Treat core24/core26 as
unvalidated: snapcraft's `platforms:` syntax may need adjusting.

snapcraft pack runs in this directory and leaves parts/, stage/, prime/ here
(owned by the container's root mapping); they are gitignored.

Verify current Snapcraft Kernel plugin keys before modifying:
https://documentation.ubuntu.com/snapcraft/latest/reference/plugins/kernel_plugin/
